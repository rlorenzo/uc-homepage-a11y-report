Methodology

This report is generated automatically on the first of each month using axe-core (via @axe-core/playwright) running against the homepages of all 10 University of California campuses and the Office of the President.

Automated accessibility testing tools typically detect only 30 to 40 percent of potential accessibility issues. This report should be treated as a lower-bound estimate. Manual testing, assistive technology testing, and user testing with people who have disabilities are essential for a complete accessibility evaluation.

Tests cover WCAG 2.0 A/AA, WCAG 2.1 A/AA, and WCAG 2.2 AA success criteria. Each page is loaded in headless Chromium, allowed to reach network idle, and then analyzed.

Source code: github.com/rlorenzo/uc-homepage-a11y-report
